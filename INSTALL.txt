FOXES & PIE — PWA

REGULAR STARTUP
Open index.html in a browser. The game works without installation.
Menu → Full screen. Browsers may block fullscreen mode for local files.

INSTALL AS AN APP
1. Host index.html, manifest.webmanifest, sw.js, and the icons directory together on a static HTTPS site. The files may be hosted in a subdirectory.
2. Open the game's address in your phone's browser.
3. Open the game menu → Install game. If the browser does not show an installation dialog, use its menu and select “Install app” or “Add to Home screen”.
4. Wait for the message confirming that the game is ready to work offline.
5. Launch the game from its home screen icon. The app requests fullscreen mode and landscape orientation; the browser determines which modes it supports.
On iPhone: Share → Add to Home Screen. This usually opens the app without an address bar rather than hiding all system controls.

Files opened through file:// or content:// (from Downloads) cannot register a service worker or be installed as a PWA. These features require HTTPS. For testing on a computer, http://localhost also works.

Live game: https://ramantsitou.github.io/fox-and-pie/
The same build can also be hosted on another static HTTPS service.
If the PWA was installed from the previous ChatGPT Sites address, install it once from the new GitHub Pages address. Future updates will come from the new site. Storage and progress from the old origin do not transfer automatically.

NEW RULES
After a failed attempt, the level stays the same, but control passes to the other player. Lost pie is not restored.
Each damaging hit on a boss drops 2 coins. Nets and misses do not award coins. When retrying a level, coins earned during the previous attempt are rolled back along with the other wave-related coin changes.
If a boss reaches the pie, its health in the next attempt decreases by 10% compared with the previous attempt, but never below 65% of its initial health. The reduction resets when advancing to a new level.

AUTOMATIC UPDATES
After a new version is published to the site, the installed PWA does not need to be reinstalled. It checks for updates when it next opens or the player returns to the game. While the app is open, it also checks once a minute.
The new version downloads completely, then the app restarts after the current wave ends. The level, player, coins, traps, and remaining pie are preserved. If the browser does not allow session state to be stored, the app displays a message that an update is ready instead of restarting.
After this update mechanism is first introduced, reopen the old version once while connected to the internet. A closed app is not guaranteed to update immediately in the background.
